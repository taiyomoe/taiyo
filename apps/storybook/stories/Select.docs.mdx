## Overview

Select components allow users to choose from a list of options. They provide a clean, accessible interface for single or multiple selections with clear visual feedback. The select component is perfect for forms where users need to pick from predefined choices.

<Canvas of={SelectStories.Default} />

### Disabled

Disabled selects prevent user interaction and provide visual feedback that the field is not available.

<Canvas of={SelectStories.Disabled} />

### Multiple Selection

Multiple selection allows users to choose several options at once, with each selected item clearly indicated with a checkmark.
