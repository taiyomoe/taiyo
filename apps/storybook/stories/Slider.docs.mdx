## Overview

Sliders allow users to select a value or range of values from a continuous range by dragging a handle along a track. They're perfect for adjusting settings like volume, brightness, or any numeric value where precise control is needed.

<Canvas of={SliderStories.Default} />

### Range

Range sliders enable users to select a range of values with two handles, perfect for filtering data or setting min/max boundaries.

<Canvas of={SliderStories.Range} />

### Disabled

Disabled sliders prevent user interaction and provide visual feedback that the control is not available.
