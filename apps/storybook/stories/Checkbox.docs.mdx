## Overview

Checkboxes allow users to select one or more options from a set. They provide a clear visual indication of selection state and are commonly used in forms, settings, and lists where multiple selections are possible.

### Disabled

Disabled checkboxes prevent user interaction and provide visual feedback that the option is not available.
