## Overview

Radio groups let users pick a single option from a small set of mutually exclusive choices. Compose a `RadioGroup` with one `RadioGroupItem` per option; pair each item with a `Label` for accessibility.

<Canvas of={RadioGroupStories.Default} />

### Selected By Default

Pass `defaultValue` to pre-select an option in an uncontrolled group (use `value` + `onValueChange` for the controlled variant).

<Canvas of={RadioGroupStories.SelectedByDefault} />

### Disabled

Disabled radio groups prevent user interaction and dim every item in the group.

<Canvas of={RadioGroupStories.Disabled} />

### Read Only

Read-only groups keep the current selection visible and focusable but reject changes.

<Canvas of={RadioGroupStories.ReadOnly} />

### Invalid

Setting `aria-invalid` on the items surfaces a destructive border, signalling a validation error.

<Canvas of={RadioGroupStories.Invalid} />

### Horizontal

The default layout is a vertical stack; override the className with `flex-row` to lay the options out horizontally.

<Canvas of={RadioGroupStories.Horizontal} />
