## Overview

Field is the accessibility wrapper around a single form control. It wires up a `FieldLabel`, `FieldControl`, `FieldDescription` and `FieldError` to the same `name`, propagates `disabled` / `invalid` state to its children, and integrates with `Form` for validation.

<Canvas of={FieldStories.Default} />

### Composition

A full Field composition: label, control, helper description, and one `FieldError` per native validity reason. Errors only render when the matching `ValidityState` flag is set on the control.

<Canvas of={FieldStories.Composition} />

### Disabled

Setting `disabled` on the Field disables the underlying control and dims the label.

<Canvas of={FieldStories.Disabled} />

### Invalid

When the field is invalid (either from controlled `invalid`, from native validity, or from a `validate` callback), `FieldError` blocks render and the control receives `data-invalid`. Use `match={true}` to display an error regardless of native validity state.

<Canvas of={FieldStories.Invalid} />

### With Description

A description provides supplemental guidance and is automatically associated with the control via `aria-describedby`.
