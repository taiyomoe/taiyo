## Overview

Pagination splits long lists across multiple pages and lets users navigate between them. It's a purely presentational primitive — bring your own routing or state, then mark the current page with `isActive` on `PaginationLink`.

<Canvas of={PaginationStories.Default} />

### First Page

When the user lands on the first page, mark the previous control as disabled and highlight page 1 as active.

<Canvas of={PaginationStories.FirstPage} />

### With Ellipsis

Use `PaginationEllipsis` to compress long page ranges around the current page, keeping endpoints visible without showing every number.

<Canvas of={PaginationStories.WithEllipsis} />

### Long Range

Smaller datasets can show the full page range without ellipses.

<Canvas of={PaginationStories.LongRange} />

### Compact

Trim the control down to just previous and next when the total page count is unknown or doesn't need to be shown.
