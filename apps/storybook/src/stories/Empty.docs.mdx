## Overview

Empty is a compositional primitive for empty states — typically rendered when a list, search, or section has no data to show. Compose `EmptyHeader`, `EmptyMedia`, `EmptyTitle`, `EmptyDescription` and an optional `EmptyContent` slot for a call-to-action.

<Canvas of={EmptyStories.Default} />

### With Action

An empty state can include an `EmptyContent` block that hosts a primary action button to help the user move forward.

<Canvas of={EmptyStories.WithAction} />

### Media Variants

`EmptyMedia` accepts a `variant` prop: `default` renders the icon inline, while `icon` wraps it in a small card with decorative stacked back layers to evoke an empty stack.

<Canvas of={EmptyStories.MediaVariants} />

### Title Only

The smallest useful composition: a header with just a title, when no media or description is needed.
