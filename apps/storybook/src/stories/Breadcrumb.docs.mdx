## Overview

Breadcrumbs help users understand where they are in a hierarchical navigation tree and provide a quick way to jump back up the path. They are composed from `BreadcrumbList`, `BreadcrumbItem`, `BreadcrumbLink`, `BreadcrumbPage`, and `BreadcrumbSeparator` parts.

<Canvas of={BreadcrumbStories.Default} />

### With Custom Separator

`BreadcrumbSeparator` accepts children to override the default chevron — pass any icon to brand the separator.

### With Ellipsis

Use `BreadcrumbEllipsis` to collapse a long trail when there isn't room to render every intermediate step.
