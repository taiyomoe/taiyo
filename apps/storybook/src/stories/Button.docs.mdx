## Overview

Buttons are clickable elements that are used to trigger actions. They communicate calls to action to the user and allow users to interact with pages in a variety of ways. Button labels express what action will occur when the user interacts with it.

<Canvas of={ButtonStories.Default} />

### Variants

Buttons come in several visual variants to communicate intent: a primary `default`, a muted `secondary`, low-emphasis `outline`/`ghost`/`link`, and the destructive pair for irreversible actions.

<Canvas of={ButtonStories.Variants} />

### Sizes

Text buttons scale from `xs` to `xl` to fit different layout densities.

<Canvas of={ButtonStories.Sizes} />

### Icon Sizes

Square `icon-*` sizes are reserved for icon-only buttons and mirror the text sizes from `icon-xs` to `icon-xl`.

<Canvas of={ButtonStories.IconSizes} />

### Disabled

Disabled buttons prevent user interaction and provide visual feedback that the action is not available.

<Canvas of={ButtonStories.Disabled} />

### Loading

Loading buttons show a spinner and prevent interaction while an action is being processed.

<Canvas of={ButtonStories.Loading} />

### With Icon

Buttons can include icons alongside text to enhance visual communication and help users quickly understand the action. Icons should be relevant to the action and placed consistently (typically to the left of the text).

<Canvas of={ButtonStories.WithIcon} />

### Icon Only

Icon buttons allow users to take actions, and make choices, with a single tap.

<Canvas of={ButtonStories.IconOnly} />
