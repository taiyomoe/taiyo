## Overview

A two-state button that flips between pressed and unpressed. Use it for formatting controls, view toggles, or any independent on/off affordance — group multiple together with `ToggleGroup` when the selection is mutually related.

<Canvas of={ToggleStories.Default} />

### Variants

Toggle ships with a borderless `default` and a bordered `outline` style for use on neutral surfaces.

<Canvas of={ToggleStories.Variants} />

### Sizes

Sizes (`sm`, `default`, `lg`) scale the toggle to match surrounding controls.
