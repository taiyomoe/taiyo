## Overview

Tabs organize content into multiple panels that share the same screen real estate, letting users switch between related views without navigating away. The set is composed of `Tabs`, `TabsList`, `TabsTrigger`, and `TabsContent`.

<Canvas of={TabsStories.Default} />

### Underline

`TabsList` accepts a `variant` prop. The `underline` variant swaps the pill-style indicator for a thin bar that sits on the active tab's edge.

<Canvas of={TabsStories.Underline} />

### Vertical

Set `orientation="vertical"` on the root `Tabs` to lay triggers in a column alongside the panels.

<Canvas of={TabsStories.Vertical} />

### Disabled

Individual triggers can be disabled by passing `disabled` to `TabsTrigger`; the tab becomes unfocusable and unactivatable.

<Canvas of={TabsStories.Disabled} />
