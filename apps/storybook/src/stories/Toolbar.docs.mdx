## Overview

`Toolbar` is a composable container that wires roving focus and keyboard navigation across a row of controls — buttons, links, inputs, and groups. Compose it with `ToolbarButton`, `ToolbarLink`, `ToolbarInput`, `ToolbarGroup`, and `ToolbarSeparator`.

<Canvas of={ToolbarStories.Default} />

### With Separator

Drop a `ToolbarSeparator` between sections of related controls to visually partition the toolbar.

<Canvas of={ToolbarStories.WithSeparator} />

### With Group

`ToolbarGroup` clusters related items so they read as a unit and stay aligned.

<Canvas of={ToolbarStories.WithGroup} />

### With Input and Link

Toolbars can host more than buttons — text inputs and links participate in the same roving-focus model.

<Canvas of={ToolbarStories.WithInputAndLink} />

### Vertical

Pass `orientation="vertical"` to stack toolbar items into a side rail.

<Canvas of={ToolbarStories.Vertical} />

### Disabled

A disabled toolbar disables every item inside while preserving their roving-focus order for accessibility.
