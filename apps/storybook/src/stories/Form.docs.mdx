## Overview

Form is a thin wrapper over the native `<form>` element with consolidated validation. It owns the `validationMode` for nested `Field`s, surfaces a strongly-typed `onFormSubmit` handler, and accepts externally-provided `errors` (e.g. from a server action) keyed by field `name`.

### Composition

A real-world signup form built from `Form`, multiple `Field`s, and `Button`s for submit/reset.

### With Server Errors

Pass an `errors` object keyed by field `name` to display validation messages returned by a server. Each Field's `FieldError` will render the matching message until the user edits the value.
