## Overview

A segmented control picks exactly one value from a few options laid out as a pill. It is a radio group underneath, so arrow keys move the selection and one option always stays selected. Use `Tabs` instead when each option shows its own panel. Pass `fullWidth` to stretch it across its container.

### Small

Set `size="sm"` on each `SegmentedControlItem` for dense surfaces such as settings sheets.

### Disabled

`disabled` on the root dims every option and blocks changes.
