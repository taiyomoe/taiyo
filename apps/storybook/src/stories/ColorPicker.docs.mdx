## Overview

A color picker shows the current color as a button. It opens a popover with a saturation and brightness area, a hue slider, a hex field and, in browsers that support it, an eyedropper. It is controlled: pass a hex `value` and update it from `onChange`. The area and hue slider work with arrow keys (hold Shift for bigger steps).
