## Overview

`ScrollArea` is a passive container that adds a styled, auto-hiding scrollbar to overflowing content while preserving native keyboard and pointer behaviour.

<Canvas of={ScrollAreaStories.Default} />

### With Scroll Fade

Toggling `scrollFade` masks the edges of the viewport so content gracefully fades into view at the start and end of the scrollable axis.

<Canvas of={ScrollAreaStories.WithScrollFade} />

### With Scrollbar Gutter

Enable `scrollbarGutter` to reserve space for the scrollbar so content does not shift when overflow appears.

<Canvas of={ScrollAreaStories.WithScrollbarGutter} />

### Horizontal

`ScrollArea` handles both axes automatically — any horizontally overflowing content gets a matching horizontal scrollbar.

<Canvas of={ScrollAreaStories.Horizontal} />
