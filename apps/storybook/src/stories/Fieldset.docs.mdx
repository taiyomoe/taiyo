## Overview

Fieldset groups related `Field`s under a common `FieldsetLegend`. It renders a native `<fieldset>` so the `disabled` attribute cascades to all nested form controls and assistive tech announces the legend alongside each label.

<Canvas of={FieldsetStories.Default} />

### Composition

A typical Fieldset contains a legend and multiple `Field`s, each with their own label, control, and optional description.

<Canvas of={FieldsetStories.Composition} />

### Disabled

Disabling the Fieldset disables every nested control in one go — useful while a form section is loading or waiting on another value.
