## Overview

Progress bars communicate the completion of an ongoing task. Unlike a meter, they're tied to a determinate, time-bound operation — e.g. an upload or a multi-step flow.

<Canvas of={ProgressStories.Default} />

### Empty

A progress at `0` renders an empty track — useful as the starting state of an operation.

<Canvas of={ProgressStories.Empty} />

### Half

A progress at `50` fills half the track.

<Canvas of={ProgressStories.Half} />

### Full

A progress at `max` (default `100`) fills the track entirely.

<Canvas of={ProgressStories.Full} />

### Indeterminate

Pass `value={null}` to render the indeterminate state when progress is unknown.

<Canvas of={ProgressStories.Indeterminate} />

### With Label

Compose `ProgressLabel` and `ProgressTrack` to render a labelled progress bar.

<Canvas of={ProgressStories.WithLabel} />

### With Value

Add `ProgressValue` next to the label to display the formatted current value alongside the track.

<Canvas of={ProgressStories.WithValue} />

### Custom Range

Override `min` and `max` to use the progress for non-percentage scales, such as multi-step flows.

<Canvas of={ProgressStories.CustomRange} />
