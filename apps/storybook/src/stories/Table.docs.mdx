## Overview

The Table is a compositional set of primitives — `Table`, `TableHeader`, `TableBody`, `TableFooter`, `TableRow`, `TableHead`, `TableCell`, and `TableCaption` — for rendering tabular data with consistent typography, spacing, and hover/selection states.

<Canvas of={TableStories.Default} />

### Card

Set `variant="card"` to render the table inside a rounded, bordered card surface — useful when the table sits on a colored page background.

<Canvas of={TableStories.Card} />

### Selected Row

Set `data-state="selected"` on a `TableRow` to surface a persistent selection background.
