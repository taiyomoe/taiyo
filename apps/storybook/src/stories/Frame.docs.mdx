## Overview

Frame is a layout container for stacked card-like panels — used for settings pages, dashboards, and any "list of grouped sections" UI. The outer `Frame` provides a muted padded surface and inserts a small gap between consecutive `FramePanel`s. `FrameHeader`, `FrameTitle`, `FrameDescription` and `FrameFooter` are typographic slots for the panel's content.
