# TimeInput

[Source code](https://github.com/taiyomoe/taiyo/blob/develop/packages/ui/src/components/ui/time-input.tsx)

## Overview

A typable 24-hour time field. Type `930`, `14:30` or `2:30 pm`, commit with Enter or by leaving the field, and unreadable text reverts. The arrow keys step by a minute, and the clock button opens hour and minute columns.
