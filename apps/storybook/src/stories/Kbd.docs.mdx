## Overview

`Kbd` is a tiny inline primitive that renders a single keyboard key — use it to visualize shortcuts, hotkeys, and command palette accelerators alongside text or inside menu items.

<Canvas of={KbdStories.Default} />

### With Modifiers

Wrap multiple `Kbd` elements in `KbdGroup` to render a chord such as `⌘K`.
