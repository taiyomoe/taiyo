## Overview

Alert dialogs interrupt the user with a critical, blocking choice — typically a destructive or irreversible action that needs explicit confirmation. Unlike a regular dialog, they cannot be dismissed by clicking outside; the user must pick one of the available actions.

<Canvas of={AlertDialogStories.Default} />

### Bare Footer

`AlertDialogFooter` accepts a `variant` prop. The default footer renders a separator and a muted background; `bare` removes them for a flush look.

<Canvas of={AlertDialogStories.BareFooter} />

### No Mobile Stick

By default the popup sticks to the bottom of the viewport on mobile widths. Disable this with `bottomStickOnMobile={false}` to keep the centered desktop layout on all screens.
