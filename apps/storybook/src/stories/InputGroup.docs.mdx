## Overview

`InputGroup` wraps an `InputGroupInput` or `InputGroupTextarea` and decorates it with addons — icons, text affixes, buttons, or keyboard shortcuts — that sit inside the same focus ring as the input itself.

<Canvas of={InputGroupStories.Default} />

### Leading Icon

A common pattern: place an icon on the leading edge to hint at the input's purpose (search, email, etc.).

<Canvas of={InputGroupStories.LeadingIcon} />

### Trailing Icon

Use `align="inline-end"` on an `InputGroupAddon` to anchor decorations to the trailing edge.

<Canvas of={InputGroupStories.TrailingIcon} />

### With Text

`InputGroupText` renders a non-interactive textual affix, perfect for protocols, units, or domains.

<Canvas of={InputGroupStories.WithText} />

### With Button

Addons can host real interactive controls — typically a small ghost button for inline actions like clearing the input.

<Canvas of={InputGroupStories.WithButton} />

### With Kbd

Pair a search input with a `Kbd` shortcut indicator to signal the keyboard accelerator.

<Canvas of={InputGroupStories.WithKbd} />

### Block Start

Addons aligned to `block-start` stack the affix above the input, useful for composer-style fields.

<Canvas of={InputGroupStories.BlockStart} />

### Block End

`block-end` puts the addon below the input — commonly a footer row with a submit button.

<Canvas of={InputGroupStories.BlockEnd} />

### Disabled

Disabling the inner input dims the entire group.

<Canvas of={InputGroupStories.Disabled} />

### Invalid

When the input is `aria-invalid`, the group adopts the destructive border and ring.

<Canvas of={InputGroupStories.Invalid} />
