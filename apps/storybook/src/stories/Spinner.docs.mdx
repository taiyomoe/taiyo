## Overview

The Spinner communicates an indeterminate loading state. It renders a continuously rotating icon with an accessible `role="status"` and `aria-label="Loading"` so assistive technologies announce progress while a request is in flight.

<Canvas of={SpinnerStories.Default} />

### Sizes

The spinner has no built-in size variants — sizing is controlled through Tailwind utility classes (`size-*` or `h-*`/`w-*`) passed via `className`.

<Canvas of={SpinnerStories.Sizes} />

### Colors

The icon inherits `currentColor`, so its tone is set with text-color utilities (`text-primary`, `text-muted-foreground`, etc.).
