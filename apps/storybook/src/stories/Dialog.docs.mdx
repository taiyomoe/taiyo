## Overview

Dialogs interrupt the user with a focused task or confirmation that requires attention. Use them sparingly for short flows like editing a record, confirming a destructive action, or surfacing required input.

<Canvas of={DialogStories.Default} />

### Without close button

Pass `showCloseButton={false}` to hide the built-in close affordance when the dialog already provides explicit close actions in its footer.

<Canvas of={DialogStories.WithoutCloseButton} />

### Bare footer

The footer accepts a `variant="bare"` to drop the divider and muted background, blending the actions with the panel for lighter-weight dialogs.

<Canvas of={DialogStories.BareFooter} />

### No mobile stick

By default the dialog docks to the bottom of the viewport on small screens. Pass `bottomStickOnMobile={false}` to keep it centered on every breakpoint.

<Canvas of={DialogStories.NoMobileStick} />
