## Overview

Cards are compositional containers built from `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`/`CardPanel`, and `CardFooter` parts. They group related content with a soft shadow and rounded border.

<Canvas of={CardStories.Default} />

### With Action

`CardAction` docks a control to the top-right of the header — useful for an edit button or icon menu without disturbing the header grid.

<Canvas of={CardStories.WithAction} />

### Frame

`CardFrame` (with `CardFrameHeader`/`CardFrameTitle`/`CardFrameDescription`/`CardFrameFooter`) wraps a stack of inner `Card`s into a single visually grouped surface — useful for settings sections that bundle multiple sub-cards.

<Canvas of={CardStories.Frame} />
