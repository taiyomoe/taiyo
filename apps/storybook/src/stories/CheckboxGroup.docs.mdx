## Overview

`CheckboxGroup` co-ordinates a set of `Checkbox` items so their values can be read together. Each child `Checkbox` is matched to the group via its `name` prop, and the group surfaces the selected names through `value`/`defaultValue`.

<Canvas of={CheckboxGroupStories.Default} />

### With Default Value

Pass `defaultValue` (uncontrolled) or `value` (controlled) as an array of checkbox `name`s to pre-select members of the group.

<Canvas of={CheckboxGroupStories.WithDefaultValue} />

### Disabled

Setting `disabled` on the group disables every checkbox it contains.
