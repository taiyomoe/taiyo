## Overview

Switches are binary toggles that turn an option on or off. They are typically used for settings that take effect immediately, without needing a confirmation step.

<Canvas of={SwitchStories.Default} />

### Checked

Use `defaultChecked` (uncontrolled) or `checked` (controlled) to set the initial on state.

<Canvas of={SwitchStories.Checked} />

### Disabled

A disabled switch prevents user interaction and dims the control to communicate that the setting is currently unavailable.

<Canvas of={SwitchStories.Disabled} />

### Disabled Checked

The disabled state preserves the current value, so a switch can be both disabled and checked.

<Canvas of={SwitchStories.DisabledChecked} />
