## Overview

`NumberField` is a numeric input with built-in increment and decrement buttons, keyboard-arrow stepping, and constraint support. Compose it from `NumberFieldGroup`, `NumberFieldDecrement`, `NumberFieldInput`, and `NumberFieldIncrement`.

<Canvas of={NumberFieldStories.Default} />

### Sizes

`NumberField` accepts a `size` prop with `sm`, `default`, and `lg` variants that adjust input height and stepper button padding.

<Canvas of={NumberFieldStories.Sizes} />

### With Min and Max

Constrain the accepted range with `min` and `max`; the steppers disable themselves at the boundaries.

<Canvas of={NumberFieldStories.WithMinMax} />

### With Step

The `step` prop controls the increment per stepper click or arrow-key press, including fractional values.

<Canvas of={NumberFieldStories.WithStep} />

### Disabled

Disabled fields prevent interaction and dim the entire group.

<Canvas of={NumberFieldStories.Disabled} />

### Read Only

Read-only fields display a value that cannot be edited but remain focusable for selection and copying.

<Canvas of={NumberFieldStories.ReadOnly} />

### Invalid

Setting `aria-invalid` on the inner input switches the group to the destructive border and ring.

<Canvas of={NumberFieldStories.Invalid} />

### With Label

Pair the field with a `Label` (linked via `htmlFor`/`id`) for accessible labelling.

<Canvas of={NumberFieldStories.WithLabel} />

### With Scrub Area

`NumberFieldScrubArea` renders a draggable label that scrubs the value horizontally — a power-user input for design tools.

<Canvas of={NumberFieldStories.WithScrubArea} />
